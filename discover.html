Question-1: What are the different ways to select an element in the DOM?

There are many different ways to select an element in the DOM.
getElementById(): Selects a single element by its unique ID, returning the first matching element.
getElementsByTagName(): Selects all elements with a specified tag name, returning an HTMLCollection.
getElementsByClassName(): Selects all elements with a specified class name, returning an HTMLCollection.
getElementsByName(): Selects all elements with the same name attribute, returning a NodeList.
querySelector(): Selects the first element that matches a specified CSS selector, returning a single element.
querySelectorAll(): Selects all elements that match a specified CSS selector, returning a static NodeList.

Question-2: What is the difference between innerHTML, innerText, and textContent ?

innerHTML: deals with the entire HTML structure.
innerText: focuses on the visually rendered text content.
textContent: retrieves all raw text content, including hidden elements and preserving source formatting.

Question-3: What is event delegation in the DOM?

In the context of events, a delegate is an intermediary or pointer-like mechanism between the event source and the code that handles the event.

Question-4: What is event bubbling in the DOM?

When an element (like a button) is clicked, an event is directed to the element. If an event handler is set for the element, the event handler is triggered. Then the event "bubbles up" to the elements parent. If an event handler is set for the parent, this event handler is triggered.

Question-5: How do you create, add, and remove elements using JavaScript?

1. Creating an Element: To create HTML elements there is a method called document.createElement('tagName') . The tagName parameter can be any valid HTML element like h1 tag p tag a tag etc. The method returns a new HTML element.
2. Adding an Element: After creating an element, you need to add it to the DOM, typically as a child of an existing element. appendChild(): This method adds an element as the last child of a specified parent element. insertBefore(): This method allows you to insert an element before a specified child element of a parent.
3. Removing an Element: To remove an element from the DOM, you can use one of two primary methods: removeChild(): This method is called on the parent of the element you want to remove and takes the child element as an argument.remove(): This method is called directly on the element you want to remove, and it removes itself from its parent. This is a more modern and often more convenient method.
